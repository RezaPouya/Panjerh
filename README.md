![OpenGL](https://img.shields.io/badge/OpenGL-%23FFFFFF.svg?style=for-the-badge&logo=opengl) ![C++](https://img.shields.io/badge/c++-%2300599C.svg?style=for-the-badge&logo=c%2B%2B&logoColor=white)

## 📖 Overview

This is my first project on OpenGL. I slowly intend to learn it from various sources.

This repository serves as a personal learning log and a practical playground for understanding core OpenGL concepts, from drawing a simple triangle to building more complex 3D graphics applications. The code here will evolve as my understanding grows.

## 🎯 Goals

The primary goal of this project is to build a solid foundation in modern OpenGL (3.3+). The learning path is structured as follows:

- [x] **Setup:** Create a basic window with GLFW and configure the build system.
- [ ] **The Basics:**
  - [ ] Drawing a simple triangle.
  - [ ] Understanding the graphics pipeline (Vertex Buffers, Shaders).
  - [ ] Working with vertex and fragment shaders (GLSL).
- [ ] **Intermediate Concepts:**
  - [ ] Texturing and blending.
  - [ ] Transformations (Translate, Rotate, Scale).
  - [ ] Coordinate Systems (Model, View, Projection).
- [ ] **Advanced Topics (Future):**
  - [ ] Lighting (Phong, Blinn-Phong).
  - [ ] Model Loading.
  - [ ] Basic 3D rendering.

## 🛠️ Tech Stack & Dependencies

* **Language:** C++
* **Graphics API:** OpenGL (3.3+ Core Profile)
* **Window Management:** [GLFW](https://www.glfw.org/)
* **OpenGL Function Loading:** [GLAD](https://glad.dav1d.de/)
* **Mathematics:** [GLM](https://github.com/g-truc/glm) (OpenGL Mathematics)
